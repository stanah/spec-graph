# 機能要件（カテゴリ別分割）

要件定義のサンプルファイルを機能カテゴリごとに分割して管理しています。

## ファイル構成

### 1. エディタ機能 (`editing-features.yaml`)
- **内容**: テキストエディタとマインドマップの双方向同期、バリデーション、フォーマット変換
- **要件数**: 3件
- **主要機能**:
  - エディタ↔マインドマップの双方向同期
  - リアルタイムバリデーション
  - JSON/YAML相互変換

### 2. ビジュアル表示機能 (`visualization-features.yaml`)
- **内容**: マップ、テーブル、ドキュメントビューの表示機能
- **要件数**: 5件
- **主要機能**:
  - インタラクティブマインドマップ描画
  - テーブルビュー機能
  - リッチドキュメントビュー
  - ビュー切り替えシステム

### 3. UI/UX機能 (`ui-ux-features.yaml`)
- **内容**: ユーザーインターフェース、操作性、エラーハンドリング
- **要件数**: 6件
- **主要機能**:
  - ノード状態インジケーター
  - キーボード中心の操作体系
  - 検索・フィルタリング
  - ノード操作UI

### 4. データ管理機能 (`data-management-features.yaml`)
- **内容**: データバリデーション、タイプ管理、依存関係管理
- **要件数**: 6件
- **主要機能**:
  - JSON Schemaバリデーション
  - ドキュメントタイプ管理
  - ID・依存関係管理
  - データエクスポート

### 5. VSCode統合機能 (`vscode-integration-features.yaml`)
- **内容**: VSCode拡張としての統合機能
- **要件数**: 4件
- **主要機能**:
  - VSCode拡張基盤
  - プレビューペイン
  - ファイルシステムAPI統合
  - コマンドパレット統合

## 使用方法

1. **概要確認**: `../requirements-overview.yaml` で全体構造を確認
2. **詳細確認**: 各カテゴリファイルで具体的な要件を確認
3. **開発時**: 関連するカテゴリファイルを参照して実装

## 利点

- **保守性**: 関連する要件がまとまって管理されている
- **可読性**: カテゴリごとにファイルが分離されて読みやすい
- **拡張性**: 新しいカテゴリを追加しやすい
- **並行開発**: チーム開発でのコンフリクトを減らせる
